Sistem Operasi Jaringan (NOS)

Fondasi sistem operasi jaringan: arsitektur multi-user headless, hierarki direktori FHS Debian 12, hak akses POSIX (chmod/chown), kontrol proses systemd, dan manajemen paket APT.

Instalasi Debian 12 Server

Praktik instalasi sistem operasi headless: verifikasi ISO Netinst, partisi storage ext4 & swap, tasksel software selection tanpa GUI, bootloader GRUB, serta setup IP statis interfaces.

Pengelolaan OpenSSH Server di Debian 12, login tanpa password via Public Key ed25519, hardening port & firewall UFW, transfer file (SCP/SFTP/Rsync), serta SSH Tunneling.

Arsitektur asynchronous event-driven, konfigurasi Virtual Host Server Blocks, Reverse Proxy microservice, hardening banner identitas, dan sertifikat enkripsi SSL/HTTPS.

Database Server (MariaDB)

Modul 06

Firewall Server (UFW)

Konsep packet filtering, default deny policy, pembukaan port layanan (TCP/UDP), isolasi subnet IP, urutan rule, rate limiting brute-force, dan analisis ufw log.

Pencegahan intrusi otomatis berbasis log, konfigurasi jail.local (bantime, findtime, maxretry), proteksi brute-force SSH & Web, manajemen unban IP, serta audit log.

Petunjuk Belajar Mandiri Siswa

  1. Pilih materi modul secara bertahap mulai dari Modul 01 (Sistem Operasi Jaringan) hingga Modul 07 (Uptime Kuma).
  2. Pelajari teori singkat pada setiap bab, lalu perhatikan tabel perintah yang disediakan.
  3. Gunakan tombol Coba di sebelah perintah untuk memasukkan sintaks langsung ke simulator terminal.
  4. Selesaikan seluruh target pada tab Lab Terminal sampai tanda centang hijau muncul di setiap misi.
  5. Kerjakan kuis evaluasi pada tab Latihan untuk menguji pemahaman konsep sebelum melanjutkan ke modul berikutnya.
