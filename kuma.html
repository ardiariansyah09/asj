Modul 08 · Monitoring Layanan

Uptime Kuma: Pantau Kesehatan Server

Uptime Kuma dikelola melalui dashboard web, jadi praktik modul ini menggunakan simulasi UI monitor (bukan terminal CLI). Amati perubahan status saat layanan berhenti dan pulih kembali.

Tujuan Praktik

  • Membedakan pemeriksaan HTTP, TCP port, dan status layanan.
  • Membuat monitor Web, MariaDB, dan SSH untuk server lab.
  • Mengamati insiden downtime serta pemulihan layanan.
Dashboard · srv-wikrama
Simulasi pemantauan lokal

Riwayat Kejadian

    Langkah Evaluasi

    1. Klik Tambah monitor lab dan periksa tiga tipe monitor yang muncul.
    2. Hentikan MariaDB pada simulasi; monitor TCP port 3306 harus berubah menjadi DOWN.
    3. Pulihkan layanan, pastikan monitor kembali UP, lalu baca riwayat kejadian.
    4. Di server nyata, Uptime Kuma dapat dipasang dengan Docker atau Node.js dan dashboard diakses melalui browser.

    Contoh target: HTTP http://localhost:80, TCP 127.0.0.1:3306, dan TCP 127.0.0.1:22. Reverse proxy Nginx memerlukan dukungan WebSocket.
