Materi Praktik: Instalasi & Konfigurasi Pasca-Instalasi Debian 12 Headless

Tujuan Pembelajaran

  • Memahami persiapan instalasi: verifikasi checksum ISO, media instalasi bootable, dan mode firmware (UEFI vs BIOS Legacy).
  • Menjelaskan perbedaan installer teks (*Debian Text Mode Install*) vs GUI (*Graphical Install*) pada server produksi.
  • Mengonfigurasi parameter regional, hostname identitas, dan nama domain server.
  • Memahami arsitektur keamanan akun: penetapan password root dan pembuatan akun reguler non-root.
  • Menganalisis skema partisi hard disk: penentuan partisi root (`/`), `/home`, `/var`, dan alokasi memori virtual (`swap`).
  • Memahami utilitas *Tasksel Software Selection*: mengapa server produksi wajib mematikan *Debian Desktop Environment* (GNOME/XFCE) dan hanya memilih *Standard System Utilities* & *SSH Server*.
  • Menguasai konfigurasi pasca-instalasi (*post-install*): penentuan IP Static di `/etc/network/interfaces`, DNS resolver di `/etc/resolv.conf`, serta eskalasi hak akses sudo.

Cara Memakai Modul

  1. Mulai dari tab Simulasi Installer dan ikuti alur boot sampai login pertama; pilih mode teks atau grafis saat menu boot.
  2. Pelajari panduan visual tahapan instalasi Debian 12 pada tiap tab bab navigasi di atas.
  3. Gunakan tombol Coba pada tabel langkah kerja untuk memindahkan perintah verifikasi dan pasca-instalasi ke konsol simulator.
  4. Tersedia mesin Debian 12 server baru: srv-wikrama untuk mengonfigurasi IP statis, gateway, repositori, dan privilege sudo.
  5. Kredensial latihan untuk terminal simulator: siswa123.
⚠️ Terminal pada tab Lab Terminal adalah lingkungan Debian 12 setelah instalasi. Ketik reset kapan saja untuk mengembalikan konfigurasi lab ke kondisi awal.

Mode Firmware: UEFI vs BIOS Legacy

💡 Pilihan di Menu Boot: Pilih menu Install (mode Text / ncurses) atau Graphical Install. Pada hakikatnya kedua mode menghasilkan sistem operasi yang 100% sama. Untuk server, teknisi jaringan umumnya memilih mode teks karena responsif dan membutuhkan memori RAM minimal saat instalasi.

Bab 2. Pengaturan Bahasa, Regional & Jaringan Awal

🎯 Tujuan: Mengonfigurasi parameter lokal sistem, zona waktu, hostname identitas mesin, dan domain jaringan.

Tahapan Parameter Regional

  • Language: Direkomendasikan memilih English untuk mencegah terjemahan istilah teknis yang rancu di terminal server.
  • Country/Territory: Pilih other → Asia → Indonesia agar format penulisan waktu dan mata uang sesuai standar nasional.
  • Keymap: Pilih American English (standar layout keyboard QWERTY yang beredar di Indonesia).

Penamaan Hostname & Domain

Hostname adalah nama unik komputer server ini di dalam jaringan lokal (misal: srv-wikrama). Domain name adalah sufiks penamaan domain internal sekolah (misal: tkj.wikrama.sch.id atau sekolah.lan).

Bab 5. Tasksel & Pemilihan Paket Perangkat Lunak

🎯 Tujuan: Menghemat sumber daya RAM dan meningkatkan kestabilan server dengan memilih instalasi headless (*tanpa GUI desktop*).

Mengapa Server Wajib Tanpa GUI?

Pada langkah Software selection (tasksel), installer menampilkan daftar paket yang ingin dipasang:

Bab 6. Pemasangan Bootloader GRUB 2

🎯 Tujuan: Memasang bootloader GRUB pada disk utama agar server dapat melakukan proses booting secara mandiri.

Peran GRUB 2 (Grand Unified Bootloader)

GRUB 2 adalah program pertama yang dieksekusi oleh firmware komputer saat mesin dinyalakan. GRUB bertugas menampilkan menu pilihan sistem operasi, memuat kernel Linux (vmlinuz) dan berkas initrd ke dalam memori RAM, lalu menyerahkan kontrol sistem sepenuhnya kepada kernel.

Menentukan Target Device

Pilihan InstallerTarget PenulisanKeterangan
Install the GRUB boot loader to your primary drive?Pilih YesMemastikan bootloader terpasang di disk utama.
Device for boot loader installation:Pilih /dev/sda atau /dev/vda (Bukan enter manually!)Pilih nama perangkat hard disk fisik secara eksplisit, bukan pada partisi (`/dev/sda1`).
💡 Setelah GRUB selesai dipasang, installer akan meminta kamu mencabut flashdisk instalasi atau me-release ISO virtual CD-ROM, lalu menekan Continue untuk me-reboot mesin masuk ke Debian 12 pertama kali.

Bab 7. Konfigurasi Pasca-Instalasi (Post-Install)

🎯 Tujuan: Menetapkan pengalamatan IP Static di `/etc/network/interfaces`, mengatur DNS nameserver, dan mendaftarkan hak akses sudo.

Tiga Langkah Wajib Administrator Pasca-Instalasi

Tugas AdministratorBerkas / Perintah KunciTujuan Operasional
1. Konfigurasi IP Statis/etc/network/interfacesServer tidak boleh berganti-ganti alamat IP agar klien dapat mengakses layanan jaringan secara konsisten.
2. DNS Resolver/etc/resolv.confMendaftarkan IP DNS Server (Gateway/Google) agar server dapat menerjemahkan nama domain saat unduh paket.
3. Hak Akses Sudousermod -aG sudo [user]Memberi hak eskalasi root pada akun siswa agar tidak perlu login sebagai root langsung.

Sintaks `/etc/network/interfaces` untuk IP Statis

auto eth0
iface eth0 inet static
    address 10.0.0.20/24
    gateway 10.0.0.1

Daftar Misi Mandiri

    Latihan Soal & Rangkuman

    Rangkuman Inti

    • Debian 12 Netinst adalah media instalasi paling ideal untuk server karena menghasilkan instalasi minimalis dan stabil.
    • Server jaringan wajib diinstal dalam mode Headless (tanpa desktop environment) untuk memaksimalkan efisiensi RAM dan stabilitas 24/7.
    • Mengosongkan form password root saat instalasi secara otomatis akan mengaktifkan wewenang sudo pada akun pengguna pertama.
    • Skema partisi server minimal menyertakan partisi sistem root (/) dengan format ext4 dan area memori virtual swap.
    • Bootloader GRUB 2 harus dituliskan langsung pada perangkat disk utama (seperti /dev/sda atau /dev/vda).
    • Tiga konfigurasi krusial pasca-instalasi: alamat IP statis di /etc/network/interfaces, DNS nameserver di /etc/resolv.conf, dan repositori APT resmi di /etc/apt/sources.list.
